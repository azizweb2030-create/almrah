# المراح V2 - منصة إدارة المواشي

منصة رقمية متخصصة في إدارة المواشي والأغنام.

## الميزات
- تسجيل الولادات ومتابعة القطيع
- متابعة مراحل نمو المواليد (بهم → مفطوم → جاهز)
- قسم البيطرة والعزل
- تسجيل النفوق
- مساعد AI ذكي
- تقارير PDF
- إشعارات تيليغرام
- نظام اشتراكات

## Stack
- Next.js 14 + TypeScript
- Supabase (PostgreSQL + Auth)
- Tailwind CSS
- Claude AI
